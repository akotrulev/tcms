BigCase · brand exploration · 2026-07-31

Three directions. Pick one.

Each is a complete system — mark, lockup, app icon, palette, type scale, and a live slice of the case list so you can see it doing the actual job. Open any card.

The shared constraint: in a test management tool, status colour is load-bearing data. Green/red/amber/violet are spoken for, so no direction may use them as a brand colour. All three keep the status palette byte-identical to today's index.css and differ only in the chrome around it.
