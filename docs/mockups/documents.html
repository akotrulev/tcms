3. The guest flow

The checkout must be completable by a shopper who has never signed in. Everything below describes that path; the signed-in path differs only in which fields are pre-filled.

§3.2 linked by ACME-101 Open the epic

A shopper who has never signed in must be able to complete an order with an email address and a delivery address, and be offered — never required — an account at the end.

The cart is keyed to the browser session and must survive a sign-in performed mid-checkout. Nothing in the guest path may write to the customer table before the order is placed.

4. Errors

Every validation failure names the field it came from and is shown beside that field. A summary at the top of the form is additional, never the only place an error appears.
