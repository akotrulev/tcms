The table is the page

No card, no panel, no "Test cases" heading repeating the rail's active item. The filter strip and the footer are the only chrome, and both say something the table cannot.Was: a PageHeader block, then a Paper, then the grid — three borders before the first row.

Filters are chips you can see and remove

Applied filters render as removable chips with a live 86 of 1 284, so a table that looks empty always names what emptied it. Real buttons with focus rings, not clickable divs.UX#117 · UX#115 · UX#90

Proportion before number

Last result is a 56px bar and 7/8, not a percentage. Two identical percentages over different denominators was a real defect on the run screens; a bar cannot tell that lie.

Em dash means "no value", never zero

A case that never ran shows — and Never run, not 0%. Health is a word beside its colour, so the column survives a colour-blind reader and a greyscale screenshot.UX#37

Nine tables, one skeleton

Sticky mono column heads, 10px row padding, hover at 2.5% white, one sort arrow. A person who learns to read the cases table has learned all nine.

The subtitle line carries the second fact

Rather than a twelfth column, the row's own cell carries a quiet second line — who started a run, which token filed a proposal, why a schedule is paused. It wraps; a column would have truncated.UX#113 · UX#111

Empty is a sentence about the product

Artifacts says what an artifact is and where they come from, because the honest answer to "no artifacts" is that you cannot make one here.UX#79

Projects is a picker, not a grid

Three numbers per card, each a bar you can compare down the column. A table of three rows and three columns would have been a table for the sake of one.
