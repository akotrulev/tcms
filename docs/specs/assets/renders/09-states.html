What a suite actually is

A suite is flat. It is a named collection whose members arrive by three routes, and it is not a folder in a tree — there is no nesting, and a case can belong to many suites at once.

Filed94
Added32
Tagged20

Filed is the case's home suite, set when it is written. Added means somebody put it here by hand. Tagged means the suite has a tag rule and the case carries the tag — so tagged membership changes when the case's tags do, without anybody touching the suite.

This is why a suite's count can change without an edit, and why Refunds shows 146 while only 94 cases name it as home.
Help is the same document surface as a case and a doc page — 70ch, same gutter, same rule. It is written in the product, not linked to a wiki.

Help is a fourth document surface
