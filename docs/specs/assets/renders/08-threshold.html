"This instance has no sign-up" is said, not implied

A missing link is a puzzle. One sentence naming what actually happens — an administrator invites you — is the difference between a support ticket and none.

The left panel is the only marketing in the product

It says what the tool is for in two sentences, and it carries the instance hostname and version, so a person landing on the wrong internal URL can tell.

Keep me signed in is on the password path only

It appears with the password field, not before one is known to be needed. A checkbox for a flow that will not happen is noise at the exact moment noise costs most.
