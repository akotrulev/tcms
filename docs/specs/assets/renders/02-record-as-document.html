A report is a file, and the preview says so — a light page on a recessed ground, at its own proportions. It is the one surface in the product that is not dark, because the artifact it shows is going to be printed and mailed.

One timeline, three screens

Case history, suite history and the audit trail share a mono gutter, a 7px dot and a rule between events. The eye learns it once.

Every read screen names its version

Run rows, history rows and executions all say which version ran. Showing today's text beside yesterday's verdict is the quietest way a test-management tool can lie.

The proposal's verdict comes last

Document, then evidence, then decision — top to bottom in the reading order. Accept sits under the excerpts it is a judgement about, not in the toolbar.UX#35 · UX#92

The report preview stays light

The one deliberate break in the palette. A PDF preview drawn dark misrepresents the thing being downloaded, and the ground behind it is --field so it reads as a document in a viewer.
