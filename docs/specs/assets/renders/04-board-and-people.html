Dragging W-138 · drop to move, or press Esc to cancelSpace lift   ←→ column   ↑↓ position   Space drop

Every drag has a keyboard twin

Space lifts a card, arrows move it, Space drops it, Esc cancels — and the footer says so while a card is lifted, so it is discoverable rather than documented. WCAG 2.2 AA requires a single-pointer alternative; a keyboard path is the stronger answer.UX#103 · UX#41

Blocked earns colour; Done loses it

One column is tinted, because one column is a question for a human. Done drops to 62% opacity — present for counting, quiet for scanning.Was: five identical columns, so the eye had to read all five to find the trouble.

A blocked card says why, on the card

Two lines under a rule. The reason is the only thing a blocked item is for; putting it behind a click made the column a list of names.

Overdue is a word in red, not a red card

Colour alone would fail a greyscale print and a colour-blind reader, and a whole red card would drown the card's own priority chip.UX#37

Access is two gates: company membership, then an explicit project grant. This chart is the second gate, drawn.

Three arms, three fills

A matrix built the obvious way — the grants that name a project — draws direct and team grants identically and omits company-wide defaults entirely. Three fills and a legend are the whole reason this chart is worth having.

Gaps are the point of the screen

An org chart that only shows what exists is a directory. The gaps panel names what is missing and what it costs — nobody can approve a plan there — and is derived from the catalogue rather than curated.
